# HRM User Role System Documentation

## Overview

The HRM system implements a comprehensive user role system where:
- **Customers** are assigned to specific **Doctors** and **Nurses**
- **Doctors** can only see customers assigned to them in the Django admin
- **Nurses** can only see customers assigned to them in the Django admin
- **Admin users** can see all customers and manage assignments
